## Введение
**Russian Taxes Calculator** — это Python-библиотека, предназначенная для автоматизации расчета основных налогов Российской Федерации. Проект решает задачу точного вычисления суммы налога с учетом прогрессивных шкал и различных налоговых ставок.

---

## Архитектура и логика решения

### 1. Ядро расчетов (`taxes.py`)
Для каждого налога была реализована система **прогрессивных шкал**.

#### Поддерживаемые налоги:
* **НДФЛ (Прогрессивный):** Реализована актуальная шкала с 5 порогами (13%, 15%, 18%, 20%, 22%) для доходов от 2.4 млн до 50 млн+ рублей.
* **НДС (VAT):** Расчет по стандартной ставке 20% с возможностью переопределения.
* **Налог на прибыль:** Фиксированная ставка 20%.
* **Налог на имущество:** Базовая ставка 2.2% с поддержкой кастомных региональных ставок.

### 2. Makefile
Для удобства разработки используется `Makefile`, который инкапсулирует сложные команды:
* `make run`: Автоматическое создание виртуального окружения и установка зависимостей.
* `make check`: Комплексная проверка проекта, включающая проверку импортов, типизацию (`mypy`) и линтинг (`flake8`, `black`).
* `make clean`: Очистка проекта от временных файлов и кэша Python.

### 3. Контроль целостности (`script.sh`)
Проект включает вспомогательный bash-скрипт для автоматической сверки используемых в коде импортов с файлом `requirements.txt`. Это гарантирует отсутствие "забытых" зависимостей при подготовке релиза.
